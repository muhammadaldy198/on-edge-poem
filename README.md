Two people carry a pane of glass upstairs. Either can decide when it comes down.

## Run

Use Python 3.13 with a writable `/output` directory:

```sh
python3.13 -P -s main.py
```

The program writes the poem as UTF-8 to `/output/entry.txt`. It needs no packages or network.
